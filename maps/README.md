# Maps

`village.json` (Tiled JSON, 40×30, 16 px tiles) and `tileset.png` are generated by
`npm run generate-map` (`scripts/generate-map.ts`). Both are committed; rerun the script after
changing the layout in `scripts/map-generator/`. The map opens and edits in Tiled.

The tileset is drawn procedurally (flat colors with light pixel detail) so the repo needs no art
assets. It can be swapped for a Kenney CC0 tileset by replacing `tileset.png` and remapping tile
ids; the sim only reads the layers below, not tile art.

## Layer conventions

| Layer     | Kind         | Meaning                                                                                                                                                                         |
| --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ground`  | tile layer   | Floor art                                                                                                                                                                       |
| `walls`   | tile layer   | Any non-zero tile blocks movement and sight                                                                                                                                     |
| `decor`   | tile layer   | Art only (furniture, trees, doors); never blocks                                                                                                                                |
| `places`  | object layer | Rectangles; `name` is the place name, bool `isIndoor`. Indoor rectangles include their walls                                                                                    |
| `objects` | object layer | One 16×16 rectangle per interactable at its tile; properties `name`, `kind`, `place`, `interactions` (JSON string array), plus `stock` for stock objects and `isOpen` for doors |
| `spawns`  | object layer | Points named after places                                                                                                                                                       |

Tiles outside every place belong to `village road`. Tileset tiles carry a bool `collides` property
for Tiled users.
